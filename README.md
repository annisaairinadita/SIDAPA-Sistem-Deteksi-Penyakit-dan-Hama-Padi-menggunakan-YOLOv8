# SIDAPA-Sistem-Deteksi-Penyakit-dan-Hama-Padi-menggunakan-YOLOv8
YOLOv8-based real-time detection system for rice plant diseases and pests, integrated with an automated treatment recommendation engine and an interactive Streamlit web app. Trained on 2,462 images from Sigi Regency, achieving up to 0.887 mAP@50 at 101–108 FPS.
